# StudyOS

A modern, lightweight student workspace built with vanilla HTML, CSS, and JavaScript.

StudyOS helps students organize their academic life in one simple and local-first workspace.

## ✨ Features

- 📊 Student dashboard
- 📚 Subject management
- 🎓 Course tracking
- ✅ Task and deadline management
- 📝 Rich text document editor
- 📅 Calendar
- 📈 Study progress tracking
- 🗂️ Flashcards
- 🔍 Task and content search
- 💾 Local data storage
- 🌙 Light and dark themes
- 📤 Data export and import
- ⚡ No account or backend required

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage

## 🚀 Getting Started

No installation is required.

Simply open `index.html` in your web browser.
