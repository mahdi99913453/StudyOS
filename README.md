# StudyOS

A modern and lightweight student workspace built with HTML5, CSS3, and Vanilla JavaScript.

StudyOS is designed to help students organize their studies, manage tasks, track courses, write documents, and monitor their academic progress in one simple workspace.

## ✨ Features

- 📊 Student dashboard
- 📚 Subject management
- 🎓 Course tracking
- ✅ Task and deadline management
- 📝 Rich text document editor
- 📅 Calendar
- 📈 Study progress tracking
- 🔍 Task and content search
- 💾 Local data storage
- 🌙 Light and dark themes
- 📤 Data export and import
- ⚡ No account or backend required

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage

## 🚀 Getting Started

No installation is required.

Simply download or clone the repository and open:

`index.html`

in your web browser.
